# Blog fotoğrafları — The Journal (foto-hazır sistem)

Buraya bir dosya bırakır bırakmaz ilgili yerde **otomatik** görünür; dosya yoksa
konuya uygun mevcut görsel (fallback) ya da zarif degrade kullanılır — asla
kırık/boş görsel çıkmaz. Her yazı: 1 kapak (hero) + 1–2 gövde-içi görsel.

## Kurallar
- Format **.jpg**, yatay için ~1600×900, dikey için ~1000×1500; < 400 KB
- Yalnızca hakkına sahip/lisanslı görseller
- Başlık ve konumla uyumlu olmalı (geo-SEO: doğru şehir = doğru sinyal)
